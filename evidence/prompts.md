# Запити до Cursor AI Agent

Це три самостійні prompts для демонстрації роботи в Cursor. Відкрийте папку проєкту у Cursor, виберіть Agent і послідовно вставте запити.

## Запит 1 — початкова версія

Створи адаптивний односторінковий сайт українською мовою для персонального фітнес-тренера Марка Левченка. Використай HTML, CSS і JavaScript без зовнішніх бібліотек. Зроби темний графітовий стиль з лаймовим акцентом, чітку типографіку, головний екран з CTA, секцію про тренера, три картки послуг і контакти. Додай семантичну розмітку та мобільну версію. Не додавай форми з вигаданим збереженням даних. Запуск має бути через `npm run dev`.

## Запит 2 — нова секція та функція

Додай секцію відгуків між послугами та контактами. Зроби перемикання трьох відгуків кнопками «попередній/наступний» на звичайному JavaScript, оновлюючи цитату, ім’я, опис і лічильник. На мобільному екрані меню має відкриватися кнопкою-гамбургером, закриватися після переходу за посиланням і коректно оновлювати `aria-expanded`. Збережи кольори й типографіку чинного дизайну.

## Запит 3 — дизайн і повернення через Git

Для перевірки зміни тимчасово зроби головну кнопку повністю округлою (border-radius: 999px) і збільш її горизонтальні відступи до 26px. Перевір вигляд на широкому та вузькому екрані. Потім поверни попередній дизайн кнопки через Git: покажи відмінність і виконай відновлення файла зі збереженого commit. Після відновлення перевір, що сторінка знову використовує початкову прямокутну кнопку.

## Як зафіксувати докази

Зробіть знімок екрана після кожного запиту у вікні Agent, а для третього також покажіть змінений елемент і Git-відновлення. Додайте сюди скриншоти з Cursor. `git-history.txt` містить історію контрольної точки дизайну, створену для цього архіву.
