# Матеріали для здачі

Проєкт: `index.html`, `styles.css`, `script.js`, `server.mjs`, `package.json`.

Готові prompts для трьох етапів Cursor Agent: `prompts.md`. Вони ще не були вставлені у вікно Cursor Agent у цій сесії. Перед здачею виконайте їх і додайте реальні знімки екрана: сторінка у браузері, дерево файлів у Cursor, термінал з `npm run dev`, кожен prompt і результати агентських змін. Git-відновлення в цьому проєкті вже закріплене у `.git` та описане у `git-history.txt`.
